# Grade Levels

Grade Levels are managed from **Revolt-X School → School Setup → Grade Levels**.

Administrators can now:

- Add a new grade level.
- Edit the grade code, name, stage, promotion/display order and active status.
- Keep inactive grade levels for history while preventing them from being used in new setup flows.

## Fields

- **Code**: Short unique code, for example `KG1`, `P1`, `JHS1`.
- **Name**: Display name, for example `Primary 1`.
- **Stage**: `Primary` or `JHS`.
- **Display / promotion order**: Numeric order used for promotion sequencing.
- **Status**: Active or inactive.
